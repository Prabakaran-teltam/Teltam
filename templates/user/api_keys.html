REST API Documentation & Usage Examples

Pass your secret key using the X-API-Key header or Bearer authorization header.

POST http://{{ request_host }}/api/v1/translate/text/
# cURL Example:
curl -X POST http://{{ request_host }}/api/v1/translate/text/ \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY_HERE" \
  -d '{
    "text": "Hello world, welcome to Teltam AI!",
    "source_lang": "auto",
    "target_lang": "hi"
  }'
Sample Response (200 OK):
{
  "status": "success",
  "source_lang": "auto",
  "target_lang": "hi",
  "original_text": "Hello world, welcome to Teltam AI!",
  "translated_text": "नमस्ते दुनिया, टेल्टम एआई में आपका स्वागत है!",
  "character_count": 34
}
POST http://{{ request_host }}/api/v1/translate/document/
# cURL Example:
curl -X POST http://{{ request_host }}/api/v1/translate/document/ \
  -H "X-API-Key: YOUR_API_KEY_HERE" \
  -F "file=@/path/to/document.pdf" \
  -F "target_lang=ta" \
  -F "output_format=pdf"
Sample Response (200 OK):
{
  "status": "success",
  "history_id": 42,
  "source_lang": "auto",
  "target_lang": "ta",
  "extracted_text": "...",
  "translated_text": "...",
  "download_url": "http://{{ request_host }}/download/document/42/"
}
POST http://{{ request_host }}/api/v1/translate/voice/
# cURL Example:
curl -X POST http://{{ request_host }}/api/v1/translate/voice/ \
  -H "X-API-Key: YOUR_API_KEY_HERE" \
  -F "file=@/path/to/recording.mp3" \
  -F "target_lang=es"
Sample Response (200 OK):
{
  "status": "success",
  "transcribed_text": "Hello, how can I help you today?",
  "target_lang": "es",
  "translated_text": "Hola, ¿cómo puedo ayudarte hoy?"
}
