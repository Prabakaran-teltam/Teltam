1. Authentication & API Keys

Secure API key verification for registered & subscribed developers.

All REST API requests require a valid Developer API Key generated from your User Dashboard API Keys Page. API key generation and usage are restricted to active subscription plans.

Authentication Methods: You can authenticate by passing your key in any of the following formats:
  • HTTP Header: X-API-Key: teltam_sk_your_secret_key (Recommended)
  • HTTP Authorization Header: Authorization: Bearer teltam_sk_your_secret_key
  • URL Query Parameter: ?api_key=teltam_sk_your_secret_key

2. Base Server Endpoint

All API requests must be sent over secure HTTPS to the base domain:

https://{{ request_host }}/api/v1/

Live Text Translation API

/api/v1/translate/text/

Translates raw text payloads in real-time into any of 150+ supported target languages while preserving original formatting, bullet points, and tone.

Request Parameters (JSON / Form Data)
Parameter Type Required Description
text string Required The source string or text content to be translated.
target_lang string Required Target language code (e.g., es, hi, ta, fr, de).
source_lang string Optional Source language code. Default is auto for automatic language detection.
Code Example Sandbox
curl -X POST https://{{ request_host }}/api/v1/translate/text/ \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY_HERE" \
  -d '{
    "text": "Welcome to Teltam AI developer translation service.",
    "source_lang": "auto",
    "target_lang": "hi"
  }'

Document Translation API

/api/v1/translate/document/

Upload PDF, DOCX, TXT, or Image files (scanned or digital). Automatically performs high-accuracy OCR, translates content, and provides a formatted download URL.

Request Parameters (Multipart Form Data)
Parameter Type Required Description
file file Required Document binary file (.pdf, .docx, .txt, .jpg, .png). Max size: 15MB.
target_lang string Required Target language code (e.g. ta, es, de).
output_format string Optional Output file format (pdf, docx, or txt). Default is pdf.
cURL Example
curl -X POST https://{{ request_host }}/api/v1/translate/document/ \
  -H "X-API-Key: YOUR_API_KEY_HERE" \
  -F "file=@/path/to/sample_document.pdf" \
  -F "target_lang=ta" \
  -F "output_format=pdf"
Sample JSON Response (200 OK)
{
  "status": "success",
  "history_id": 105,
  "source_lang": "auto",
  "target_lang": "ta",
  "extracted_text": "Extracted text content from document...",
  "translated_text": "மொழிபெயர்க்கப்பட்ட ஆவணத்தின் உள்ளடக்கங்கள்...",
  "download_url": "https://{{ request_host }}/download/document/105/"
}

Voice Translation API

/api/v1/translate/voice/

Upload audio recordings (MP3, WAV, M4A, WebM, OGG). Transcribes audio using neural Whisper engine and returns translated text.

cURL Example
curl -X POST https://{{ request_host }}/api/v1/translate/voice/ \
  -H "X-API-Key: YOUR_API_KEY_HERE" \
  -F "file=@/path/to/voice_sample.mp3" \
  -F "target_lang=es"
Sample JSON Response (200 OK)
{
  "status": "success",
  "transcribed_text": "Hello, thank you for choosing Teltam translation services.",
  "target_lang": "es",
  "translated_text": "Hola, gracias por elegir los servicios de traducción de Teltam."
}
POST /api/v1/translate/camera/

Accepts base64 camera image frames or image file payloads to perform real-time Vision OCR extraction and translate into target language.

Request Parameters (JSON / Form Data)
Parameter Type Required Description
image_data string Required* Base64 encoded camera frame image string (e.g. data:image/jpeg;base64,...).
file file Required* Image file upload (JPG, PNG, WEBP, BMP) if image_data base64 is not provided.
target_lang string Required Target language code (e.g., es, ta, fr, hi).
source_lang string Optional Source language code. Default is auto for automatic detection.
Sample JSON Response (200 OK)
{
  "status": "success",
  "has_text": true,
  "source_lang": "auto",
  "target_lang": "es",
  "extracted_text": "WELCOME TO TELTAM REAL-TIME CAMERA TRANSLATION",

}

Error Codes & Response Standard

Teltam APIs return conventional HTTP status codes to indicate success or failure.

HTTP Code Status Name Description
200 OK Success Request completed successfully.
400 Bad Request Bad Request Missing or invalid parameters (e.g., empty text, invalid target language code).
401 Unauthorized Unauthorized Missing or invalid X-API-Key secret key.
403 Forbidden Subscription Required Key owner does not have an active paid subscription plan.
500 Server Error Server Error Internal processing failure. Try again or contact support.
